# Python for Data Science

*My solutions to the 42 **Python for Data Science** piscine: short modules that go from Python basics to data handling.*

## Progress

| Module | Topics | Status |
|---|---|---|
| **00: Starting** | Types, f-strings, `time`, list/dict comprehensions, `lambda`, `filter`, argument parsing, building and installing a package (`ft_package`) | ✅ Done |
| **01: Array** | Type-annotated list processing (BMI computation) | 🚧 In progress |

## Highlights

- `module00/ex09`: **ft_package**, a small installable package (`pyproject.toml`, wheel + sdist), see its [README](module00/ex09/README.md)
- `module00/ex08`: `ft_filter.py`, a reimplementation of the built-in `filter`
- `module00/ex07`: `filterstring.py`, a CLI filter written with a list comprehension and a lambda
- `module00/ex06`: `sos.py`, a Morse code encoder

## Run

Python 3.10+ is required.

```bash
python3 module00/ex06/sos.py "hello world"   # .... . .-.. .-.. --- / .-- --- .-. .-.. -..
```
